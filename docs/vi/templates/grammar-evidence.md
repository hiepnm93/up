# Thẻ Bằng chứng Ngữ pháp: Từ Nhận diện Quy tắc đến Diễn đạt Thực tế

Mỗi thẻ theo dõi một cấu trúc có tác động lớn. Hãy sao chép nó vào một ghi chú riêng và giữ lại câu gốc cùng lý do chỉnh sửa. Không ghi lại thông tin nhạy cảm về khách hàng, công ty, trường học, y tế hay bên thứ ba; hãy dùng dữ liệu giả lập hoặc một đoạn trích đã được rút gọn tối thiểu.

## 1. Xác định nhiệm vụ thực sự

```markdown
Date:
Situation: email / explanation / dialogue / retelling / interview / other
Audience:
What the task must let the other person understand or do:
Time, tool, and length restrictions:
Raw sample location:
```

## 2. Xác định một vấn đề cấu trúc

```markdown
My original sentence/segment:
Most likely interpretation:
Meaning I intended:
Impact: meaning-changing / task-blocking / recurring / register mismatch / low-impact
One structure tracked in this cycle:
```

| --- | --- | --- | --- |

## 3. Viết Thẻ So Sánh Ngữ Nghĩa

```markdown
Meaning I need to express:
Forms I confuse:
Example and source from reliable material:
One-sentence explanation in my words:
Counterexample or boundary:
```

Phần giải thích cần trả lời được vì sao hình thức khớp với sự kiện, thay vì chỉ sao chép định nghĩa thuật ngữ.

## 4. Giữ lại bản sửa đổi và lý do

| Phiên bản | Điều kiện | Vị trí câu/sản phẩm đầu ra | Thay đổi gì | Lý do |
| --- | --- | --- | --- | --- |
| Lần đầu | Không có gợi ý | | | |
| Đã sửa | Đã xem giải thích/phản hồi | | | |
| Làm lại độc lập | Đã đóng tài liệu | | | |

```markdown
How the other person understood the revision:
Problem still affecting the task:
Suggested style change I rejected:
```

## 5. Truy hồi qua bốn kỹ năng

| Kỹ năng | Việc nhỏ | Kết quả | Bằng chứng |
| --- | --- | --- | --- |
| Nghe | Nghe ra mối quan hệ mà cấu trúc mang lại | | |
| Đọc | Đánh dấu phạm vi, quy chiếu, hoặc mối liên kết logic | | |
| Nói | Sử dụng dưới áp lực thời gian và sửa sau khi mắc lỗi | | |
| Viết | So sánh hai bản khác nhau làm thay đổi cách người đọc hiểu như thế nào | | |

Bạn không cần dùng cả bốn kỹ năng trong mỗi lượt luyện. Hãy giữ ít nhất một quan sát từ đầu vào và một hoạt động đầu ra.

## 6. Bản ghi AI và Phản hồi

```markdown
Tool/reviewer and date:
Problem observed:
Explanation given:
Did it separate error, ambiguity, register, and style?
Dictionary, corpus, teacher, or reader check:
What I accepted/rejected, and why:
```


## 8. Chấm điểm và quyết định

Chấm điểm 0–2: `0=not completed`, `1=prompt-dependent or unstable`, `2=completed under the current condition`.

| Hạng mục | Ngày 1 | Ngày 7 | Ngày 14 | Lý do dựa trên bằng chứng |
| --- | ---: | ---: | ---: | --- |
| Giải thích được sự khác biệt giữa hình thức và ý nghĩa | | | | |
| Nhận ra nó trong một câu mới | | | | |
| Dùng được nó khi nói hoặc viết | | | | |

| Ngừng việc liên tục thay đổi ý nghĩa chính | | | | |

```markdown
Current evidence supports: continue same structure / add variation / move to another problem / pause
Evidence:

```
