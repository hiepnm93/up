# Thẻ Bằng chứng Nghe: Từ Thời Lượng Phát lại đến Tái tạo Ý nghĩa

Chép thẻ này vào một ghi chú riêng, mỗi lần dành cho một nguồn chính và một nguồn song song. Không ghi lại mật khẩu, dữ liệu khách hàng, hay âm thanh của các cuộc họp, buổi học, gia đình chưa được phê duyệt. Chỉ lưu giữ các đoạn âm thanh, bản chép lời và ghi chú có bản quyền trong phạm vi sử dụng cá nhân phục vụ học tập được cho phép.

## 1. Xác định Nhiệm vụ và Ranh giới với Thực tế

```markdown
# Listening Evidence - YYYY-MM-DD

Real situation:
Task: gist / detail / relationship / action / interaction / transfer
What must I answer, decide, or do afterwards?
Completion standard:
Confirmation, captions, and written support allowed in reality:
Recording, upload, transcript, and sharing permission:
```

Việc đào tạo có thể loại bỏ các hình thức hỗ trợ dẫn dắt. Nhưng công việc thực tế không được phép bỏ qua bước xác nhận an toàn cần thiết chỉ để chứng minh năng lực.

## 2. Tư liệu kiểm toán và điều kiện

```markdown
Main-source title, origin, and access date:
Parallel-source title, origin, and access date:
Segment length:
Reliable English transcript: human / automatic-needs-checking / none
Topic, speaker, and accent familiarity:
Device / network / room noise:
Copyright and retention boundary:
Why I will return during the next seven days:
```

| Tiêu chí | Nguồn chính | Nguồn song song | Có thể so sánh? |
| --- | --- | --- | --- |
| Nhiệm vụ và độ khó | | | |
| Độ dài và mật độ thông tin | | | |
| Chất lượng bản ghi | | | |
| Mức quen thuộc với người nói/phát âm | | | |
| Thiết bị và môi trường | | | |

Tư liệu khác nhau chưa chắc đã là điều kiện chuyển giao có thể so sánh được. Hãy giữ nhiệm vụ và độ khó gần như tương đồng.

## 3. Giữ nguyên lần xử lý đầu tiên không phụ đề

```markdown
First-pass permission: pause / speed / captions / notes / replay
One-sentence gist:
Three certain details:
Speaker stance or purpose:
Critical number / time / person / condition:
Uncertain timestamps:
Action I would take from what I heard:
First-pass answer location:
```

Không ghi đè lên lần xử lý đầu tiên sau khi phát lại hoặc kiểm tra phụ đề. Đây là cơ sở đối chiếu.

## 4. Lập bản đồ lỗi sáu lớp

| Thời điểm | Tôi tưởng mình đã nghe | Nội dung đáng tin | Lớp rào cản | Ảnh hưởng đến công việc | Hành động của chu kỳ này |
| --- | --- | --- | --- | --- | --- |
| | | | kỹ thuật / ngôn ngữ lạ / nghe-rõ-nhưng-không-hiểu / tham-chiếu-cấu-trúc / suy-diễn-ngữ-cảnh / giới-hạn-chú-ý | thay-đổi-ý-nghĩa / cản-trở-công-việc / lặp-lại / tốn-công-sức / ảnh-hưởng-thấp | |

```markdown
One to three problems that most affect the task:
Low-impact missing words I will not repair yet:
Device or fatigue effects that cannot be assigned directly to ability:
```

## 5. Sử dụng thang hỗ trợ từng bước

| Giai đoạn | Hành động | Điều gì trở nên rõ ràng? | Điều gì vẫn chưa được kiểm chứng? |
| --- | --- | --- | --- |
| 1 | Lượt xem đầu tiên không bật phụ đề | | |
| 2 | Chỉ phát lại đoạn 5-20 giây gặp vấn đề | | |
| 3 | Mở bản ghi tiếng Anh để nắm ranh giới và cấu trúc | | |
| 4 | Tra nghĩa tối thiểu, thông tin nền, hoặc bản dịch | | |
| 5 | Đóng văn bản và nghe ở tốc độ bình thường | | |
| 6 | Bỏ các hỗ trợ cũ và kiểm tra lại trên tư liệu tương đương sau 3-7 ngày | | |

```markdown
Automatic-caption errors:
What translation helped:
Meaning still triggered after the text closed:
Segment understood only while captions remained visible:
```

## 6. Tạo bằng chứng khác nhau ở mỗi lượt chạy

| Lượt | Câu hỏi | Kết quả đầu ra | Kết quả |
| --- | --- | --- | --- |
| 1 | Tôi đã dự đoán và khôi phục được gì? | Ý chính thô và chi tiết | |
| 2 | Chênh lệch xảy ra ở đâu? | Dấu thời gian và lớp rào cản | |
| 3 | Mức hỗ trợ tối thiểu đã giải thích được điều gì? | Nghe nhầm, bản ghi chép và nguyên nhân | |
| 4 | Âm thanh có kích hoạt ý nghĩa sau khi kết thúc hỗ trợ không? | Nghe lại không có văn bản | |
| 5 | Làm thế nào để tôi tái hiện và hành động? | Kể lại / quy trình / quyết định / bàn giao | |

Số lần nghe không phải là kết quả. Mỗi lượt phải tạo ra một phán đoán mới hoặc cho thấy nên dừng việc lặp lại.

## 7. Chuyển từ chép chính tả và tập nói bám theo sang giai đoạn tự tạo lập

```markdown
High-impact 5-20 second segment:
My dictation:
Reliable transcript:
Boundary / ending / reduction / stress difference:
Delayed-shadow recording:
Three keywords:
Retelling after closing the text:
Explanation after changing one fact or position:
Unfamiliar follow-up and answer:
```

Khi nói bám theo đã trôi chảy mà lúc kể lại vẫn trắng trơn, hãy rút ngắn phần bắt chước và tăng cường dựng lại ý từ các từ khóa. Khi ghi đúng từng chữ mà vẫn bỏ lửng ý chính, hãy quay lại với cấu trúc bài và các mối quan hệ trong đó.

## 8. Ghi nhận phản hồi từ AI, giáo viên và nhiệm vụ thực tế

```markdown
Tool / reviewer / model version and date:
Did it use raw audio, automatic transcript, or my candidate transcript?
Error category it proposed:
Did it invent wording, background, or speaker intention?
Teacher/peer check:
Response, action, or repair result in the real task:
What I accepted / rejected, and why:
```

AI và bản ghi chuyển lời tự động chỉ đưa ra các phương án suy đoán, chứ không phải phán quyết cuối cùng về âm thanh gốc.

## 9. Kiểm tra khả năng ghi nhớ trễ và chuyển giao

| Thời điểm | Bị loại bỏ | Điều kiện thay đổi | Đầu ra | Kết quả |
| --- | --- | --- | --- | --- |
| Ngày 1 | Không còn phụ đề đầy đủ | Nguồn chính | Lần nghe đầu và dựng lại ý nghĩa | |
| Ngày 3-7 | Đã xóa ghi chú cũ và bản ghi | Nguồn song song | Ý chính, chi tiết và hành động | |
| Ngày 14 | Đã xóa phản hồi gần đây | Người nói mới, giọng địa phương hoặc thiết bị mới | Kể lại cùng câu hỏi mở rộng chưa quen thuộc | |
| Ngày 30 | Đã đóng tất cả đề luyện tập | Cuộc họp, khóa học hoặc hội thoại thật | Hoàn thành nhiệm vụ | |

```markdown
Method still available after seven days:
Barrier that returned after material changed:
Did full-caption or translation dependence decrease?
Can I request repetition, confirm, and preserve agreement more reliably?
One variable for the next cycle:
```

## 10. Chấm điểm và quyết định

Chấm điểm 0-2: `0=not completed`, `1=prompt-dependent or unstable`, `2=completed under the current condition`.

| Hạng mục | Ngày 1 | Ngày 7 | Ngày 14 | Lý do bằng chứng |
| --- | ---: | ---: | ---: | --- |
| Giữ được mạch chính ở lần nghe đầu | | | | |
| Lấy lại các chi tiết và mối quan hệ quan trọng | | | | |
| Xác định được lớp rào cản | | | | |
| Hiểu được sau khi tắt phụ đề | | | | |
| Tái tạo, phản hồi hoặc hành động | | | | |
| Hoàn thành sau khi thay đổi tài liệu, người nói hoặc thiết bị | | | | |

```markdown
Current evidence supports: continue main source / downgrade to extensive listening / replace source / move to another problem
Most important evidence:
Conclusion I still cannot draw:
Smallest next task:
Next review date:
```
