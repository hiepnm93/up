# Thẻ Bằng chứng Từ vựng: Từ Sự Quen Thuộc với Thẻ đến Truy xuất theo Ngữ cảnh

Hãy sao chép thẻ này vào một ghi chú riêng cho một chủ đề hoặc công việc thực tế. Không đưa vào đó mật khẩu, hồ sơ khách hàng, tài liệu chưa công bố, đáp án bài thi, thông tin y tế cần bảo mật, hay tài liệu của bên thứ ba chưa được phép sử dụng. Danh sách từ hoàn chỉnh có thể được công khai mà không cần phải công khai tài liệu gốc, bản ghi âm và phản hồi.

## 1. Xác định Nhiệm vụ và các Điều kiện Bằng chứng

```markdown
# Vocabulary Evidence - YYYY-MM-DD

Real situation and audience:
Task: listen / read / speak / write / exam / hand over
Material, version, and source:
What should another person understand, decide, or complete?
Time and length limit:
Permitted captions / dictionary / translation / search / AI / people:
Privacy, copyright, confidentiality, exam, and expert boundary:
First-encounter date:
Parallel-task date:
```

Mục tiêu không phải là "những mục được thêm vào". Mà là việc hiểu, lựa chọn và truy xuất trong những điều kiện này.

## 2. Duy trì lần gặp đầu tiên không tra từ điển

```markdown
First-encounter start/end time:
Gist, relationships, and next step before lookup:
Details understood with confidence:
Places that required guessing:
Sentence or timestamp where meaning stopped:
Sense/expression I tried then:
Raw retelling, recording, cloze, or draft location:
Did it complete the real task? yes / partly / no
```

Trước tiên, hãy kiểm tra xem rào cản có phải nằm ở từ vựng hay không. Việc tách âm thanh, cú pháp, kiến thức nền, bố cục và sự tập trung cũng có thể khiến một câu trở nên khó hiểu.

## 3. Xây dựng hàng đợi quyết định cho các mục chưa biết

| Từ/cụm từ | Ảnh hưởng tới công việc | Quyết định | Căn cứ khi đó | Lần kiểm tra tiếp theo |
| --- | --- | --- | --- | --- |
| | gây chặn / quan trọng / nhỏ / không | bỏ qua / suy đoán / tra cứu nhanh / học / nhờ chuyên gia kiểm tra | | |

```markdown
Five to eight chunks entering deliberate learning:
Items to skip and why:
Items requiring a primary source or expert:
Items deferred because of capacity:
```

## 4. Ghi lại Tám Chiều cho Mỗi Đoạn Có Giá trị

Chép một lần cho mỗi đoạn:

```markdown
Word/chunk:
Task function:
Form, inflection, and derivation:
Sound, stress, and connected speech:
Current sense in my own words:
Common collocation or sentence slot:
Grammatical behaviour:
Register, politeness, stance, and identity:
Concept, referent, version, or domain boundary:
Current retrieval time and required cue:
One near-synonym/counterexample and difference:
```

Không chép nguyên cả trang từ điển để điền vào các trường. Chỉ giữ lại những gì có thể thay đổi cách hiểu hoặc cách sử dụng trong nhiệm vụ này.

## 5. Kiểm chứng nghĩa, cách kết hợp từ và nguồn

| Mục cần kiểm tra | Phương án đề xuất của tôi | Nguồn, phiên bản, vị trí | Kết quả | Không rõ |
| --- | --- | --- | --- | --- |
| Nghĩa | | | | |
| Cách phát âm | | | | |
| Cách kết hợp từ | | | | |
| Phong cách ngôn ngữ | | | | |
| Khái niệm kỹ thuật/thể chế | | | | |

```markdown
Why this dictionary/corpus fits this task:
Primary document / standard / code location:
Check date:
Who decides the high-risk term:
What evidence would change the decision:
```

Các ví dụ và lời giải thích từ AI chỉ là phương án tham khảo, không phải nguồn. Tần suất xuất hiện hay giọng điệu tự tin của mô hình không thể quyết định thuật ngữ có rủi ro cao.

## 6. Thiết kế khả năng truy xuất không cần trợ giúp

```markdown
Real intention or situational cue:
Prompt allowed on first attempt:
Prompt removed next time:
Target retrieval time:
Speaking task:
Writing task:
Person / time / topic / tone / mode to change:
```

| Lượt thử | Điều kiện | Cách diễn đạt thực tế | Thời gian truy xuất | Kết quả |
| --- | --- | --- | ---: | --- |
| Bối cảnh gốc | Ẩn đáp án | | | |

Chỉ tái hiện nguyên câu nguồn chưa phải là chuyển giao.

## 7. Hỏi Một Người Đọc Hoặc Người Nghe Thực Sự Để Kiểm Tra

```markdown
Meaning retold by the reader/listener:
Relationship, certainty, and next step they heard:
Place that required guessing or confirmation:
Did the lexical choice change fact or responsibility?
Task completed? yes / partly / no
Real response or execution result:
```

| Phản hồi | Loại | Quyết định | Lý do | Có dùng trong tác vụ song song không? |
| --- | --- | --- | --- | --- |
| | sửa chữa cần thiết / biến thể chấp nhận được / ngữ cảnh / phong cách | chấp nhận / một phần / từ chối / tạm hoãn | | |

## 8. Ghi lại Lỗi và Cách Sửa Tối Thiểu

| Mẫu lỗi | Loại | Khoảng trống có thể có | Chỉ thay đổi phần này | Điều kiện kiểm tra lại |
| --- | --- | --- | --- | --- |
| | hình thức / âm / nghĩa / cách kết hợp từ / ngữ pháp / sắc thái ngôn ngữ / truy xuất từ chậm / chuyển ngữ | | | |

```markdown
Chunks correct on cards but failed in the task:
Chunks heard but not written:
Chunks read but not heard:
Acceptable variation mislabelled as error:
Items needing a split card, lower volume, or more background:
```

## 9. Ghi nhận việc sử dụng AI và công cụ

```markdown
Tool / model / version and date:
First encounter and candidate that existed before use:
Request: sense contrast / collocation candidate / cloze / counterexample
         / audience simulation / error classification / parallel task
         / other
Scope generated or rewritten by the model:
Content that may be invented or outdated:
Dictionary / corpus / primary source / human verification:
What I accepted, rejected, or deferred, and why:
Retrieval task after closing the tool:
```

## 10. Kiểm tra khả năng ghi nhớ trễ và vận dụng

| Thời gian | Loại bỏ | Thay đổi | Đầu ra | Kết quả |
| --- | --- | --- | --- | --- |
| Cùng ngày | Đáp án và chú giải | Chủ đề gốc | Gợi nhớ theo ngữ cảnh | |
| Ngày 1 | Câu gốc | Câu và nhân vật | Truy xuất bằng nói/viết | |
| Ngày 3-7 | Gợi ý gần đây | Phương thức hoặc đối tượng | Đầu vào/đầu ra song song | |
| Ngày 14 | Thẻ cũ và phản hồi | Chủ đề mới, cùng nhiệm vụ | Đầu ra thực tế có giới hạn thời gian | |
| Ngày 30 | Tất cả gợi ý luyện tập | Tài liệu thực tế/hậu quả thực | Trình bày trọn vẹn | |

```markdown
Chunks still retrieved in time:
Chunks successful only in the original item:
Most frequent returning error:
Did the real task require less guessing or rework?
```

## 11. Chấm điểm và quyết định những gì cần giữ lại

Chấm điểm từng mục `0-2`: `0=no evidence/not completed`, `1=cue-dependent or unstable`, `2=independent under the current condition`.

| Mục | Cùng ngày | Ngày 7 | Ngày 14 | Lý do dựa trên bằng chứng |
| --- | ---: | ---: | ---: | --- |
| Nhận ra nó qua âm thanh và văn bản | | | | |
| Đánh giá đúng nghĩa hiện tại và ảnh hưởng đến công việc | | | | |
| Dùng đúng kết hợp từ, hình thức và phong vị ngôn ngữ | | | | |
| Gợi nhớ được mà không cần gợi ý, trong giới hạn thời gian | | | | |
| Truyền đạt đúng ý định cho người đọc/người nghe | | | | |
| Vận dụng được khi thay đổi chủ đề, đối tượng hoặc hình thức | | | | |

```markdown
Chunks to keep learning and why:
Chunks needing a split or new cue:
Chunks to archive:
Chunks requiring expert verification:
One condition to change next cycle:
Next review date:
```
