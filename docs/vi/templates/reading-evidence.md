# Thẻ Bằng chứng Đọc: Từ Bản Tóm tắt Hoàn thành đến Chuyển giao Thực sự

Đọc xong một văn bản là một hành động, không phải bằng chứng cho thấy bạn đã hiểu. Hãy sao chép thẻ này vào một ghi chú riêng tư, dùng cho từng bài viết, chương, phần tài liệu hoặc nhóm nguồn mỗi lần. Không ghi lại mật khẩu, dữ liệu khách hàng, thông tin của bên thứ ba chưa được phép, hay chi tiết cá nhân không cần thiết.

## 1. Xác định nhiệm vụ, độc giả và ranh giới

```markdown
# Reading Evidence - YYYY-MM-DD

Real situation:
Task: locate information / follow an argument / read documentation / build stamina / synthesise sources / support a decision
Who must know, decide, execute, or continue something after the reading?
Completion standard:
Time limit:
Dictionary / translation / search / notes / AI allowed:
Copyright, privacy, and retention boundary:
```

Viết trạng thái hoàn thành dưới dạng một kết quả cụ thể, ví dụ "chạy được ví dụ tối thiểu với phiên bản hiện tại", chứ không chỉ "đã xong".

## 2. Ghi lại Nguồn và Phiên bản

| Mục | Nguồn chính | Nguồn song song | Có thể so sánh không? |
| --- | --- | --- | --- |
| Tác giả/người duy trì, tiêu đề, liên kết | | | |
| Ấn bản, ngày xuất bản, hoặc phiên bản | | | |
| Ngày truy cập và độ dài | | | |
| Vị thế hoặc lợi ích của tác giả/tổ chức | | | |
| Ranh giới trích dẫn, hình ảnh, mã nguồn, và bản quyền | | | |
| Chủ đề, thể loại, và độ khó | | | |

Các trang web có thể thay đổi, chuyển sang tính phí, hoặc biến mất. Hãy lưu lại những thông tin trích dẫn cần thiết; không sao chép toàn bộ bài viết khi chưa được phép.

## 3. Giữ nguyên bản nháp đầu tiên chưa trau chuốt

```markdown
First-pass conditions:
First-pass time:
Did I look up every word?
One-sentence gist:
How the text moves:
Three certain details:
What the author/maintainer wants me to believe or do:
One unresolved point:
Action I would take from this understanding:
```

Hãy hoàn thành bản nháp đầu tiên trước khi xem xét lại từ ngữ hay cách diễn giải. Đừng thay nó bằng một bản dịch đã trau chuốt.

## 4. Xây dựng bản đồ rào cản sáu lớp

| Đoạn văn/trang | Nơi tôi bị vướng | Lớp rào cản | Ảnh hưởng đến công việc | Hành động trong chu kỳ này |
| --- | --- | --- | --- | --- |
| | | từ vựng/ngữ pháp / cấu trúc/tham chiếu / kiến thức nền/sơ đồ / luận điểm/bằng chứng / trình bày/kỹ thuật / sự chú ý/sức chứa | làm đổi nghĩa / cản trở công việc / lặp lại / tốn nhiều công sức / tác động thấp | |

```markdown
One to three barriers that most affect the task:
Low-impact words or sentences I will skip for now:
Possible device, version, fatigue, or environment effects:
```

Nếu gần như mọi câu đều khiến bạn không nắm được ý chính, hãy chọn tài liệu song song dễ hơn hoặc học trước các cụm từ chuyên ngành. Hạ thấp điểm khởi đầu không có nghĩa là hạ thấp đích đến.

## 5. Đối chiếu tuyên bố, bằng chứng và giới hạn

| Đoạn văn/trang | Chức năng | Tuyên bố của tác giả | Bằng chứng/ví dụ từ nguồn | Giới hạn, phản ví dụ hoặc điều chưa rõ |
| --- | --- | --- | --- | --- |
| | | | | |

```markdown
Facts stated directly:
Inference supported by the source:
My own judgment or association:
Evidence still missing:
What new evidence would change my judgment:
```

Tách biệt những gì tác giả nói với việc bạn có đồng ý hay không. Với các tuyên bố về kỹ thuật, sức khỏe, pháp lý hoặc tài chính, hãy quay lại các nguồn sơ cấp đáng tin cậy hoặc lời khuyên của chuyên gia có đủ chuyên môn.

## 6. Thẻ Thông tin Tài liệu Kỹ thuật

Đối với API, SDK, hướng dẫn chuyển đổi (migration), trợ giúp dòng lệnh, tài liệu tham khảo lỗi hoặc README, hãy thêm:

```markdown
Goal and applicable version:
Prerequisites, permissions, and environment:
Minimum input:
Expected output:
Actual output:
Defaults, ranges, order, or side effects:
Failure condition/error:
Limit explicitly stated in the source:
Part I am still inferring:
Smallest next test:
```

Đọc tài liệu mà không chạy thử, không suy luận, không tái hiện hay xác nhận ít nhất một thông tin cụ thể chỉ chứng tỏ bạn đã xem qua trang đó. Nó không chứng tỏ bạn đã thực sự nắm chắc.

## 7. Ghi lại từ chưa biết, họ từ và bản dịch

| Từ/biểu thức | Vai trò trong nhiệm vụ | Định nghĩa/họ từ/kết hợp từ đã tra | Vị trí trong nguồn | Giải thích được sau khi đóng công cụ? |
| --- | --- | --- | --- | --- |
| | cốt lõi / lặp lại / kỹ thuật / ít ảnh hưởng | | | |

```markdown
Background the translation helped me supply:
English structure, stance, or qualifier the translation may hide:
Word I decided not to check yet:
```

Số lượng từ chưa biết giúp chẩn đoán mức độ phù hợp của tài liệu nguồn; nó không trực tiếp quyết định trình độ. Họ từ hỗ trợ việc đoán nghĩa và khả năng bao phủ từ vựng, nhưng một dạng từ phái sinh thì không tự động bảo đảm dùng được.

## 8. Đối chiếu các nguồn và đưa ra kết quả đầu ra

```markdown
Shared question:
Definition, date, and evidence in source A:
Definition, date, and evidence in source B:
Omitted evidence or institutional interest:
Which differences are factual, and which are values?
```

| Kết quả đầu ra | Đối tượng | Những gì tôi đã chuyển giao | Phản hồi của đối tượng | Có căn cứ truy vết? |
| --- | --- | --- | --- | --- |
| Xác nhận / thử nghiệm tối thiểu / giải thích / biên bản quyết định / bàn giao | | | | |

Sau khi đọc xong, hãy để một người đọc, đoạn mã, quyết định hoặc nhiệm vụ tiếp theo kiểm chứng mức độ hiểu bài.

## 9. Ghi nhận Công cụ và Phản hồi

```markdown
Tool / reviewer / version and date:
Did it see the source, my first pass, or my summary?
Source locations it says I missed:
Did it confuse fact, inference, and style?
Teacher/peer/primary-source check:
What I accepted/rejected, and why:
```

AI có thể trích xuất các thuật ngữ ứng viên, đặt câu hỏi về cấu trúc và tạo các tác vụ song song, nhưng nó có thể bịa ra bản tóm tắt, trích dẫn, thông tin nền và ý định của tác giả. Hãy giữ lại bản đọc lần đầu trước khi yêu cầu nó tìm bằng chứng.

## 10. Kiểm tra ghi nhớ trì hoãn và khả năng vận dụng

| Ngày | Thứ bị bỏ đi | Điều kiện thay đổi | Sản phẩm đầu ra | Kết quả |
| --- | --- | --- | --- | --- |
| Ngày 1 | Không dùng bản dịch đầy đủ hay tóm tắt bằng AI | Nguồn chính | Lần đọc đầu và dựng lại nội dung trong năm câu | |
| Ngày 3-7 | Bỏ ghi chú cũ và từ điển | Nguồn song song | Ý chính, dẫn chứng và suy luận | |
| Ngày 14 | Bỏ phản hồi gần đây | Chủ đề hoặc thể loại mới | Giải thích, bài kiểm tra, hoặc bản ghi nhớ quyết định | |
| Ngày 30 | Đóng tất cả các gợi ý | Tài liệu thật, báo cáo, hoặc bàn giao | Bàn giao hoàn chỉnh | |

```markdown
Method still available after seven days:
Barrier that returned after the source changed:
Did word-by-word translation or summary dependence decrease?
Which post-reading action remains unstable?
One variable for the next cycle:
```

## 11. Chấm điểm và quyết định

Chấm điểm 0–2: `0=not completed`, `1=prompt-dependent or unstable`, `2=completed under the current condition`.

| Hạng mục | Ngày 1 | Ngày 7 | Ngày 14 | Lý do bằng chứng |
| --- | ---: | ---: | ---: | --- |
| Giữ được mạch chính ở lần đọc đầu | | | | |
| Tách biệt khẳng định, bằng chứng và suy luận | | | | |
| Xác định tầng rào cản và chọn hành động | | | | |
| Kiểm chứng một chi tiết kỹ thuật hoặc vị trí nguồn | | | | |
| Dựng lại sau khi đóng công cụ | | | | |
| Trình bày sau khi đổi nguồn, chủ đề hoặc thể loại | | | | |

```markdown
Current evidence supports: continue main source / downgrade to extensive reading / replace source / move to another problem
Most important evidence:
Conclusion I still cannot draw:
Smallest next task:
Next review date:
```
